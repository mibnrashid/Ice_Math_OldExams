# Math 208 syllabus (Term 261)

Textbook: Edwards, Penney & Calvis, *Differential Equations and Linear Algebra*, 4th ed.

| Sec | Topic |
|---|---|
| 1.1 | Differential equations and mathematical models (verifying solutions, $y=e^{rx}$ type) |
| 1.2 | Integrals as general and particular solutions (position/velocity/acceleration) |
| 1.4 | Separable equations; natural growth/decay; Newton's law of cooling |
| 1.5 | Linear first-order equations (integrating factor $\rho=e^{\int P\,dx}$) |
| 1.6 | Substitution methods (homogeneous $v=y/x$, $v=ax+by+c$, Bernoulli), exact equations, reducible 2nd-order (missing $y$ or missing $x$) |
| Ch. 3 | Review: Gaussian elimination, inverses, determinants (3.1–3.6) |
| 4.1 | The vector space $\mathbb{R}^3$ |
| 4.2 | The vector space $\mathbb{R}^n$ and subspaces |
| 4.3 | Linear combinations and independence of vectors |
| 4.4 | Bases and dimension |
| 4.5 | Row and column spaces (definition of rank only) |
| 5.1 | Second-order linear equations |
| 5.2 | General solutions of linear equations, Wronskian |
| 5.3 | Homogeneous equations with constant coefficients |
| 5.5 | Nonhomogeneous equations: undetermined coefficients, variation of parameters |
| 6.1 | Eigenvalues and eigenvectors |
| 6.2 | Diagonalization |
| 7.2 | Matrices and linear systems |
| 7.3 | The eigenvalue method for linear systems (real and complex eigenvalues) |
| 7.6 | Multiple eigenvalue solutions (2x2 and 3x3, generalized eigenvectors, up to p. 462) |
| 8.1 | Matrix exponentials and linear systems (up to p. 490) |
| 8.2 | Nonhomogeneous linear systems (variation of parameters only) |
| 11.1 | Review of power series |
| 11.2 | Power series solutions at ordinary points |
| 11.3 | Frobenius series solutions at regular singular points |

Typical coverage: Exam I = 1.1 to 4.2, Exam II = 4.3 to 6.2, Final = comprehensive.
Older terms may have covered slightly different sections (e.g. 5.4, 7.1, 3.x on their own). Keep
those questions and solve them with the textbook method for that section.

Prerequisites (allowed freely): Math 101/102 calculus (all integration techniques, partial fractions,
series tests), high-school algebra.

Not taught, do not use in solutions: Laplace transforms, Abel's formula, Cayley-Hamilton, trace/
determinant shortcuts for eigenvalues, Jordan forms, rank-nullity beyond counting free variables,
reduction of order formula (unless the question asks for it), operator/annihilator method.
